# Changelog

## 0.26.0 - 2026-08-12

- Added pytest, pytest-cov and Ruff configuration.
- Refactored the PDF core with clearer module names and specific exceptions.
- Added a CustomTkinter PDF editor with page rendering, navigation, zoom and PDF actions.
- Integrated the PDF editor into the main LF System menu through `[D] Editor de PDF`.
- Removed unused legacy root wrappers and consolidated PDF module names.
- Added Windows/Linux GitHub Actions quality workflow.
- Expanded tests for PDF behavior, interface state, app integration, config, database, file operations and utilities.
